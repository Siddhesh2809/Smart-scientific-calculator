# Smart Scientific Calculator (Python GUI)

A modern, dark-themed scientific calculator built using Python and Tkinter.

## Features
- **Basic Arithmetic:** Addition, Subtraction, Multiplication, Division, and Percentages.
- **Scientific Functions:** `sin`, `cos`, `tan`, Square Root (`√`), Power (`^`), and Logarithm (`log`).
- **Auto-Bracket Completion:** Automatically closes pending brackets upon evaluation.
- **Error Handling:** Gracefully handles division-by-zero and syntax errors.
- **Modern UI:** Dark-themed interface designed with standard Tkinter widgets.
